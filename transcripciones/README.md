# 🎙️ Transcripciones de Clases y Subtítulos

Coloca aquí las transcripciones de audio o video de tus clases (`.txt` o `.md`).
Puedes generarlas fácilmente usando:
- Subtítulos automáticos de Zoom / Teams.
- Modelos locales como OpenAI Whisper (`whisper mi-clase.mp3 --language Spanish`).
- Herramientas web de transcripción.

Al ejecutar **`actualizar-mi-base.bat`**, el buscador RAG indexará todas las palabras dichas por el profesor y los alumnos, permitiéndote preguntar al asistente:
- *"¿En qué minuto de la clase se explicó el error de permisos en Docker?"*
- *"¿Qué ejemplo dio el profesor cuando un compañero preguntó sobre Terraform state?"*
