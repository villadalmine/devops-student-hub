# 🧩 Exámenes de Práctica y Quizzes de Autoevaluación

En esta carpeta puedes guardar tus ejercicios, cuestionarios de autoevaluación y exámenes resueltos.

El Asistente IA (`Tutor de Estudio`) utiliza los archivos de esta carpeta en el **Modo Simulador de Examen**:
- Te hará preguntas aleatorias sobre cada clase.
- Esperará tu respuesta (`A, B, C o D`).
- Evaluará tu razonamiento con rigurosidad técnica y te explicará la fundamentación.
