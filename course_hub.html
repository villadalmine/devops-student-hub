Software Base Obligatorio (Alumni / EducaciónIT)

Tu entorno requiere 12 herramientas obligatorias para realizar los laboratorios de clase:

• Zoom Workplace
• Git for Windows
• GitHub CLI (gh) (requiere gh auth login)
• Visual Studio Code
• Docker Desktop & Docker Compose
• HashiCorp Terraform
• AWS CLI v2
• Azure CLI (az)
• Kubernetes CLI (kubectl), Helm & Minikube
• jq (JSON Processor)
Comando de Instalación en 1 Clic (PowerShell como Administrador):
powershell -ExecutionPolicy Bypass -File .\scripts\instalar-tools-devops.ps1 -SoloObligatorio
Autenticación con GitHub:

Una vez instalado GitHub CLI, ejecuta en tu terminal para vincular tu cuenta:

gh auth login
