# 📝 Notas y Apuntes Técnicos

En esta carpeta puedes organizar todas tus notas personales sobre DevOps en formato Markdown (`.md`).
**¡Eres totalmente libre de estructurar tus directorios como prefieras!**

### Ideas de organización:
- Por tecnologías: `apuntes/docker/`, `apuntes/kubernetes/`, `apuntes/terraform/`, `apuntes/aws/`.
- Por proyectos: `apuntes/proyecto-alpha/`, `apuntes/certificaciones/`.
- Por temas: `apuntes/01_cultura_y_git.md`, `apuntes/02_contenedores.md`.

Todo archivo Markdown que crees aquí o en cualquier subcarpeta será indexado automáticamente por el motor de búsqueda y el Asistente IA al ejecutar `actualizar-mi-base.bat`.
