⚡ Software Base DevOps para Windows (Core Esencial)

Instalación y diagnóstico 100% automatizado mediante Windows Package Manager (Winget). Sin dependencias externas y con scripts interactivos o desatendidos.

git

Git for Windows

Control de versiones distribuido.

winget install Git.Git
gh

GitHub CLI (gh)

Autenticación (gh auth login), PRs y repos.

winget install GitHub.cli
vs

Visual Studio Code

Editor principal para código e IaC.

winget install Microsoft.VisualStudioCode
🐳

Docker Desktop

Motor de contenerización con WSL2.

winget install Docker.DockerDesktop
tf

HashiCorp Terraform

Infraestructura como Código (IaC).

winget install Hashicorp.Terraform
aws

AWS CLI (v2)

Línea de comandos para Amazon Web Services.

winget install Amazon.AWSCLI
az

Azure CLI (az)

CLI oficial para Microsoft Azure Cloud.

winget install Microsoft.AzureCLI
k8s

Kubernetes CLI (kubectl)

Control y despliegue de clusters.

winget install Kubernetes.kubectl
helm

Helm

Gestor de paquetes para Kubernetes.

winget install Helm.Helm
mini

Minikube

Cluster local Kubernetes para pruebas.

winget install Kubernetes.minikube
jq

jq (JSON Processor)

Procesador de respuestas JSON en pipelines.

winget install jqlang.jq
