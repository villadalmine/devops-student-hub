## 🎯 1. Conceptos Clave Aprendidos

### 💡 Resumen de la Clase 1 (Ejemplo de Apunte Inicial):
- **Cultura CALMS:** C (Culture), A (Automation), L (Lean), M (Measurement), S (Sharing). DevOps no es solo instalar herramientas, es cambiar la forma en que los equipos colaboran para entregar valor continuo.
- **Métricas DORA:**
  1. *Deployment Frequency (DF):* Frecuencia con la que se despliega a producción.
  2. *Lead Time for Changes (LTTC):* Tiempo desde el commit hasta que corre en producción.
  3. *Change Failure Rate (CFR):* Porcentaje de despliegues que causan fallos.
  4. *Mean Time to Recovery (MTTR):* Tiempo medio para restaurar el servicio tras un incidente.
- **Git y GitHub CLI:** Instalamos Git for Windows y configuramos `gh auth login` para poder autenticar de forma segura sin lidiar con tokens manuales.
